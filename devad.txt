An addon is a single .ps1 file. The app runs it with the call operator (& 'addon.ps1') at start-up and keeps the LAST hashtable the script outputs. The script must not output anything else (no strings or objects outside the hashtable; use $null = ... or [void] where needed).

    Description = 'One sentence.'       # [string] tooltip on the Addons menu

    OnLoad             = { param($App)  }   # runs once when the app starts or the addon is installed
    OnDownloadStarting = { param($Info) }   # runs before each download; may return a [string] of extra yt-dlp arguments
    OnDownloadComplete = { param($Info) }   # runs after each download (successful, failed or cancelled)
